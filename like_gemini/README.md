# ✦ Gemini Canvas — Flutter Web Client

This directory contains the Flutter Web application for **Gemini Canvas**, built with the **PaperMind** editorial design system.

### 🎨 Key Highlights
- **Typography:** `google_fonts` featuring *DM Serif Display* (headlines) and *Inter* (body).
- **Design Tokens:** Warm cream Light Mode (`#F5F0E8`), Charcoal Dark Mode (`#111111`), Golden Amber accent (`#F5A623`).
- **Responsive Grid:** Desktop 3-pane layout & Mobile drawer navigation.
- **Rich Markdown Engine:** Custom parser for code blocks, inline code pills, bold text, links, and lists.

### 🚀 Running Frontend Locally
```bash
flutter run -d chrome
```
